🚀 Configuration Firebase Auth

1. Firebase Console : console.firebase.google.com → Authentication → Sign-in method

✅ Activer Google (pour l'admin)

✅ Activer E-mail/Mot de passe (pour les utilisateurs)

2. Autoriser votre domaine : Authentication → Domaines autorisés → ajouter votre URL Netlify

3. Règles Firestore :

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

4. GitHub + Netlify : Créez un repo, uploadez ce fichier HTML → "New site from Git" sur Netlify.

⚠️ Le premier administrateur se connecte via Google. Ensuite, créez les comptes Email des utilisateurs depuis ce panneau.
